# 创剧 AI 长期产品升级计划

## 已批准目标

将创剧 AI 从短期作品展示升级为无需登录即可完成真实创作闭环的长期产品，同时保留现有 Vercel 地址，不修改同级的食刻拍档、译述或其他仓库。

## 验收链路

1. 用户填写故事类型、原文、目标受众、篇幅、节奏、情绪、视角、改编重点与制作限制。
2. 输入属性必须因果改变候选方向、推荐顺序、结构结果、解释与取舍，且差异可由测试证明。
3. 用户比较至少三条创作路线，选择其中一条并进入可编辑交付稿。
4. 用户下载真实 Markdown 与 JSON 交付文件，不依赖登录或外部模型。
5. 用户提交评分与观察，反馈保存在本机，并明确改变下一轮候选排序和修订建议。
6. 页面使用完整品牌标志、字标、色彩、排版、影像方向与品牌应用规范。
7. 至少 24 张由本项目生成并自托管的 WebP 故事场景进入真实创作体验；它们必须是叙事场景，不是图标或第三方图库占位。
8. 运行时不加载 Google Fonts、外部 CDN、第三方图片或外部脚本，不向浏览器暴露任何 API key。
9. 在 320、390、430 像素宽度逐一验证完整链路、零横向溢出、可见触控目标不小于 44 像素、安全区、软键盘适配和图片裁切。
10. 移除面向一次性活动、阶段性展示和临时验收者的短期叙事；产品文档和界面统一为持续使用语境。

## 构建任务（每项执行 RED → GREEN → 重构 → 原子提交）

### 任务 1：恢复可重复测试基线

- 为 Testing Library 补齐直接依赖。
- 运行现有 Vitest、ESLint、Next 构建、公开镜像冒烟和密钥扫描。

### 任务 2：建立品牌与长期产品叙事

- 定义“场记折页”标志概念、字标、色彩、排版、影像和动效规范。
- 用本地 SVG/CSS 实现可缩放品牌标志；生成并保存品牌规范板。
- 重写界面、配置和文档中的短期展示叙事，并添加防回归扫描测试。

### 任务 3：实现因果创作引擎与闭环

- 以独立纯函数生成候选路线、分数、解释、结构、权衡和交付内容。
- 让全部关键用户属性产生可验证的因果差异。
- 将反馈写入本机并影响下一轮推荐、解释与修订动作。
- 移除登录入口和登录弹窗，让首屏直接进入创作。

### 任务 4：生成并接入自托管叙事影像

- 生成至少 24 张风格一致但叙事内容不同的故事场景。
- 转换为 WebP，保存至仓库并提供清单、用途、提示词和 SHA-256。
- 使用响应式图片、懒加载、异步解码和 `object-fit: cover` 接入候选与交付体验。

### 任务 5：移动端与静态发布验收

- 增加 Playwright 桌面与 320/390/430 项目。
- 逐宽度验证完整创作、选择、下载、反馈、下一轮变化，以及布局、触控、安全区、键盘和图片行为。
- 构建安全门控的发布产物，并对本地和 Vercel 线上地址运行相同验收。

### 任务 6：交付

- 完成全量测试、构建、凭据扫描、外部依赖扫描和产物清单。
- 提交并推送独立分支，创建 PR，部署到现有 Vercel 项目并复验固定地址。
