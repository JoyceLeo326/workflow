# 创剧 AI 静态兼容模式

## 目标

在不公开服务端代码、环境变量或任何模型凭据的前提下，为公开作品集提供一个可直接放入任意静态子目录的完整创作体验。

## 验收链路

1. 创作者填写姓名、角色、受众、优先目标、时长、交付时间与真实原文片段。
2. 本地结构引擎生成三条不同路线；每条都展示来源锚点、收益与明确代价。
3. 用户选择并确认一条路线，得到可执行的分段交付稿。
4. 用户可下载真实 Markdown 与 JSON 文件。
5. 用户记录评分与观察后，反馈在本机留存并生成下一版修订动作。
6. 所有运行时资源使用相对路径、本地字体与本地脚本；构建产物经过密钥扫描并附 SHA-256 清单。

## 输出

- 源文件：`mirror-src/`
- 构建命令：`npm run build:public-mirror`
- 可发布产物：`public-mirror/`
- 作品集目标目录：`mirrors/creative-ai/`
